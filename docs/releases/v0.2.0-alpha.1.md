# v0.2.0-alpha.1 — Project Memory public alpha

Oscillink Project Memory is a local-first continuity and control layer for coding agents. This
prerelease opens a bounded external-user alpha around one outcome: preserve corrected, cited
project history across restarts, compaction and compatible client changes without replaying raw
transcripts.

## Highlights

- Four-operation local MCP sidecar: `remember`, `recall`, `correct` and `explain`.
- Approved-only deterministic recall with exact record/revision citations, context cost,
  omissions and exclusion counts.
- Candidate-only agent writes; promotion and supersession remain externally governed.
- Exact correction lineage in both directions without silently overwriting history.
- Pinned independent-process continuity demo with no transcript transfer.
- Account-free five-minute quickstart using synthetic public data.
- Authenticated browser evidence view with explicit current/stale/unavailable states.
- Server-managed workspace export and exact-ID confirmed restore.
- Apache-2.0 source, contribution guidance, security policy and public alpha protocol.

## Verified compatibility

Direct evidence currently covers:

- the official Python MCP client over real stdio subprocesses;
- Hermes native MCP discovery of all four tools;
- OpenCode 1.18.25 recall and current-revision explanation; and
- an independent Hermes Agent continuation using MCP evidence alone.

Claude Code, Codex, Cline, Cursor and other clients are not claimed until their paths are exercised
directly.

## Try the deterministic demonstration

From a clone of this release:

```bash
PYTHONPATH= uv run --locked python scripts/run_project_memory_demo.py \
  --data-root .oscillink-demo
```

The command runs locally over stdio and requires no account or model credential. See the
[Project Memory quickstart](../project-memory-quickstart.md) for prerequisites, expected evidence
and the real sidecar command.

## Join the five-user alpha

The cohort asks participants to use Project Memory on one active project across three sessions
separated by restart or compaction. Private project data remains local; public issues contain only
sanitized workflow evidence.

Read the [public alpha commitment](../alpha-cohort.md), then use the GitHub alpha application form.

## Security and limitations

This is research and alpha software, not a security certification or production support promise.
Do not expose the service directly to an untrusted network or use it for robot, industrial,
safety-critical or other physical control. Browser terminal execution, cloud synchronization,
semantic/vector retrieval, broad client compatibility, training and physical action remain
deferred.

Report vulnerabilities through GitHub private vulnerability reporting as described in
[SECURITY.md](../../SECURITY.md). Do not place credentials, private prompts, customer data, raw
host paths, runtime databases or sensitive artifacts in public issues.

## Verification boundary

Publication requires the full deterministic verifier on Windows, immutable-range verification,
detached exact-SHA Buildbox verification and green GitHub CI on the release commit. The
[public-launch audit](../public-launch-audit.md) records the pre-public exposure review and its
limitations.
