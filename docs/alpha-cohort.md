# Project Memory public alpha

Oscillink is recruiting a bounded cohort of five coding-agent users to test whether governed
Project Memory prevents repeated explanation, stale context and repeated failed approaches on
real projects.

This is a product-evidence exercise, not a request to upload source code or private transcripts.
Project Memory runs locally and requires no account or model credential for the deterministic
demo.

## Who should apply

You are a strong fit if you:

- use a coding agent across multiple days, restarts, compaction events or client changes;
- maintain an active project where decisions and corrections matter;
- currently rely on summaries, instruction files, copied transcripts or repeated explanations;
- can run Python 3.11 and `uv` locally; and
- can complete three short sessions over roughly ten days.

Watching the demo alone does not qualify as external-user evidence. Participants must use their
own project workflow, but they should keep proprietary data local and out of public issues.

## Commitment

Participants will:

1. Record their current coding agent and continuity workaround.
2. Run the five-minute deterministic quickstart.
3. Configure Project Memory for one active project with direct setup support if needed.
4. Complete three sessions separated by restart or compaction.
5. Record one real decision, one failed approach and one governed correction.
6. Report setup, review, correction, cleanup and recovery time.
7. Identify the most valuable missing client integration or hosted/team capability.

Expected time is approximately 30 minutes for setup plus brief follow-ups after each session.

## Privacy and safety

Do not place credentials, proprietary source, raw prompts or transcripts, customer data, private
host paths, runtime databases or sensitive artifacts in a GitHub issue. Public reports should use
sanitized workflow descriptions and typed errors only. Participant evidence records remain
private unless explicitly sanitized and approved for publication.

This alpha must not control robots, industrial equipment, safety systems or other physical
actuators.
